# AI Workflow - Herramientas IA para tu rol profesional

## Objetivos

1. **Desarrollar visión estratégica de IA aplicada a workflows y productos digitales**
   - Comprender el ecosistema de IA y sus capacidades reales vs. hype en 2025
   - Identificar oportunidades de automatización e innovación con IA
   - Distinguir entre productos IA-first vs. features de IA vs. automatizaciones internas
   - Reconocer patrones de implementaciones IA exitosas y causas de fracasos comunes

2. **Dominar metodologías de validación y construcción con IA**
   - Aplicar Jobs-to-be-Done para descubrir problemas reales
   - Validar demanda utilizando técnicas Lean sin escribir código
   - Definir scope realista de implementaciones IA
   - Construir soluciones funcionales con stack no-code

3. **Construir implementaciones IA funcionales con herramientas no-code**
   - Dominar stack no-code (Claude, v0.dev, Make, Airtable)
   - Integrar APIs de IA en flujos de trabajo automatizados
   - Diseñar interfaces efectivas para soluciones IA
   - Implementar testing y validación con usuarios reales

4. **Implementar y escalar soluciones IA de forma responsable**
   - Definir KPIs y dashboards para medir impacto
   - Identificar y mitigar riesgos éticos y sesgos
   - Evaluar viabilidad técnica y planificar evolución

## Módulos y Clases

### Módulo 1: Fundamentos + Herramientas
**Semanas 1-2 | 10 horas**

**1. Fundamentos de IA + Identificar Tu Oportunidad** (2.5h)
- IA, ML, LLMs: diferencias clave sin tecnicismos
- Capacidades reales vs. limitaciones de IA en 2025
- **Patrones duales:** 4 productos IA exitosos + 3 automatizaciones de rol (Marketing, Ops, CS)
- Framework "AI Opportunity Canvas" (versión dual: producto externo O mejora de workflow)
- Setup de Claude y Perplexity como research tools
- **Taller:** Identificar oportunidad - Track A (producto) o Track B (workflow de rol) (40 min)
- **Entregable:** AI Opportunity Canvas completado (especifica track elegido)
- **Homework (2h):** Refinar canvas, identificar 5 usuarios/stakeholders, explorar soluciones similares

**2. Validación de Problemas + Research con IA** (2.5h)
- Jobs-to-be-Done framework aplicado a IA
- Técnicas de entrevistas: "The Mom Test"
- **Adaptación dual:** Validación para productos externos vs. pain points internos
- Usar Claude/Perplexity para análisis de entrevistas
- **Taller:** Interview Script + role-play (mitad productos, mitad workflows) (65 min)
- **Entregable:** Interview Script validado + Problem Definition Canvas v0.5
- **Homework (2h):** 3-5 entrevistas/conversaciones + análisis con Claude

**3. Validación Lean + Landing Page con v0.dev** (2.5h)
- Lean Startup: build-measure-learn (aplicable a productos Y workflows)
- Copywriting basado en insights de usuarios
- Introducción completa a v0.dev
- **Taller:** Landing page funcional (60 min)
  - Track A: Landing de producto para mercado
  - Track B: Landing/demo de herramienta interna para equipo
- Métricas de validación según contexto
- **Entregable:** Landing page publicada con URL pública
- **Homework (2h):** Track A: 20-30 visitas | Track B: 5-7 feedbacks internos + analizar métricas

**4. Stack No-Code Completo + Definición de Implementación** (2.5h)
- Arquitectura de stack no-code (frontend + automation + data + IA)
- Setup de Make: flujos automatizados y webhooks
- Setup de Airtable: estructura de datos relacional
- Integración de Claude API en workflows
- **Demo dual:** Mismo stack para producto SaaS vs. automatización de reportes (15 min)
- **Taller:** Flujo end-to-end funcional (80 min)
- Definición de alcance con Implementation Brief simplificado
- **Entregable:** Stack funcional + Implementation Brief v1.0 + flow visual
- **Homework (2h):** Completar brief, refinar flujo, preparar arquitectura

#### Salida del Módulo 1:
✅ Problema/oportunidad validado con 3-5 entrevistas o feedbacks  
✅ Landing page funcional (producto O herramienta interna)  
✅ Stack configurado: Claude + v0.dev + Make + Airtable  
✅ Implementation Brief v1.0 con scope definido  
✅ Flujo automatizado funcional (webhook → Airtable → Claude → output)

### Módulo 2: Construcción + Validación
**Semanas 3-5 | 15 horas**

**5. Análisis Competitivo y Benchmarking** (2.5h)
- Feature comparison matrix (5-7 competidores/alternativas)
- IA para research acelerado (Perplexity + Claude)
- **Dual:** Identificar features validadas (productos) o mejores prácticas (workflows internos)
- **Taller:** Competitive analysis con Claude (55 min)
- **Entregable:** Feature matrix + 3-5 elementos a adaptar justificados
- **Homework (2h):** Research profundo de 2 referencias + validar con usuarios

**6. Definición de Funcionalidades Críticas** (2.5h)
- Qué es un MVP/MWP (Minimum Workable Product)
- Must-have vs. Nice-to-have (priorización simple)
- User Stories con criterios de aceptación técnicos
- **Taller:** Implementation Brief v2.0 con 3-5 must-haves (50 min)
- **Entregable:** Brief v2.0 completo con criterios técnicos viables
- **Homework (2h):** Validar con 2-3 usuarios + confirmar viabilidad + crear flows

**7. Prototipado Rápido con v0.dev** (2.5h)
- Principios de diseño de interfaces IA (transparencia, feedback, control, loading states)
- Wireframing de flujos para soluciones IA
- Prototipado iterativo con v0.dev (prompts avanzados)
- **Taller:** Prototipo clickeable de 2-3 flujos clave (60 min)
- **Entregable:** Prototipo interactivo funcional (6-9 pantallas)
- **Homework (2h):** Refinar prototipo + testing con 3 usuarios + preparar assets

**8. Construcción: Integración Completa** (2.5h)
- Arquitectura de integración: frontend + IA + backend no-code
- Conexión v0.dev → Make → Airtable → Claude API
- Debugging y troubleshooting
- **Taller:** Integrar componentes (70 min)
- **Entregable:** Implementación funcional al 70-80%
- **Homework (2h):** Completar al 80% + documentar limitaciones + reclutar beta users

**9. Testing y Validación con Usuarios Reales** (2.5h)
- Diseño de pruebas de usabilidad para productos IA
- Reclutamiento de 5-7 usuarios beta (moderated testing)
- Recolección y análisis de feedback cualitativo
- Identificación de friction points
- **Taller:** Sesión de testing en vivo + análisis con Claude (60 min)
- **Entregable:** Testing report con 10+ insights documentados
- **Homework (2h):** Testing con 5-7 usuarios + análisis consolidado

**10. Métricas, KPIs y Dashboards** (2.5h)
- Definir 3-5 métricas core (vanity vs. accionables)
- KPIs para productos IA (trust, accuracy percibida, engagement)
- Framework: Input-Output-Outcome
- **Taller:** Dashboard funcional en Google Sheets (50 min)
- **Entregable:** Dashboard con tracking + datos baseline
- **Homework (2h):** Configurar tracking automático + recolectar datos + analizar trends

#### Salida del Módulo 2:
✅ Feature matrix/benchmarking (insights accionables)  
✅ Brief v2.0 con user stories y criterios técnicos  
✅ Prototipo funcional testeado  
✅ Implementación al 80% con integraciones reales  
✅ Testing report con insights de usuarios  
✅ Dashboard de KPIs con datos reales

### Módulo 3: Iteración + Presentación
**Semanas 6-8 | 15 horas**

**11. Iteración y Mejora Basada en Datos** (2.5h)
- Priorización de mejoras (Impact vs. Effort matrix)
- Framework de iteración rápida (build-measure-learn)
- **Taller:** Implementar 2-3 quick wins en vivo (75 min)
- Validar cambios con métricas (antes vs. después)
- **Entregable:** Implementación v1.1 mejorada + changelog + roadmap v1.2
- **Homework (2h):** Implementar mejoras adicionales + validar + preparar materials

**12. Preparación de Portfolio y Case Study** (2.5h)
- Estructura de case study profesional (6 secciones)
- Crear demo video efectivo con Loom (3-5 min)
- Diseñar presentación técnica de 10 min
- **Taller:** Case study + demo video (80 min)
- **Entregable:** Portfolio case study + demo + presentación
- **Homework (2h):** Refinar case study + preparar presentación final

**13. Escalado y Roadmap Futuro** (2.5h)
- Señales de product-market fit / workflow adoption
- Roadmap de evolución 3 meses (v1.0 → v1.1 → v2.0)
- Cuándo involucrar developers (transición a código)
- Limitaciones del stack no-code y cuándo migrar
- **Adaptación:** Escalado de producto vs. rollout interno
- **Taller:** Roadmap 3 meses con milestones (60 min)
- **Entregable:** Roadmap + plan de transición técnica
- **Homework (2h):** Validar roadmap con stakeholders/usuarios

**14. Ética, Sesgo y Responsabilidad en IA** (2.5h)
- Principios de IA responsable (fairness, transparency, accountability)
- Identificación de sesgos en modelos y datos
- Checklist práctico de evaluación ética
- Casos reales de productos con issues éticos
- **Taller:** Matriz de riesgos éticos + plan de mitigación (65 min)
- **Entregable:** Ethics assessment + mitigaciones
- **Homework (2h):** Evaluar implementación con checklist + mejoras éticas

**15. Viabilidad Técnica y Próximos Pasos** (2.5h)
- Evaluar viabilidad técnica actual
- Identificar limitaciones del stack no-code
- Cuándo escalar vs. cuándo pivotar
- **Dual:** Viabilidad de producto en mercado vs. viabilidad de rollout corporativo
- Roadmap personal: próximos skills a desarrollar
- Overview de pricing básico (15 min): modelos, unit economics
- **Taller:** Technical viability report + learning roadmap (70 min)
- **Entregable:** Viability report + learning roadmap personal (6 meses)
- **Homework (2h):** Plan 3-6 meses (implementación + personal) + refinar presentación

**16. Presentación Final + Reflexión Estratégica** (2.5h)
- Presentaciones finales (10 min c/u) - mix de productos y workflows
- Evaluación de pares con rúbrica estructurada
- Feedback del facilitador
- Reflexión: lecciones aprendidas y próximos pasos
- Gallery walk de portfolios
- **Entregable:** Presentación final + reflexión estratégica escrita
- **Homework:** Publicar case study en LinkedIn/portfolio

#### Salida del Módulo 3:
✅ Implementación v1.1 con mejoras validadas  
✅ Roadmap de 3 meses con milestones  
✅ Ethics assessment + mitigaciones  
✅ Technical viability report  
✅ Learning roadmap personal (6 meses)  
✅ Presentación final + case study publicado

## Proyecto Final del Curso

### **Implementación IA Funcional + Portfolio Profesional**
Proyecto construido iterativamente durante 8 semanas.

**Dos tracks válidos:**
- **Track A (Producto):** Producto digital IA desplegado para mercado externo
- **Track B (Workflow):** Herramienta/automatización IA para optimizar rol profesional

**Componentes del proyecto:**
- Problem Definition Canvas: Problema validado
- Implementación funcional: Desplegada y accesible vía URL
- Testing Report: Insights de 5-7 usuarios beta
- Dashboard de KPIs: Métricas en tiempo real
- Roadmap: Evolución planificada 3 meses
- Ethics Assessment: Riesgos y mitigaciones
- Portfolio Case Study: Documentación completa

**Entregables finales:**
- Implementación funcional desplegada (link público)
- Demo video profesional (3-5 min)
- Portfolio case study completo
- Presentación final de 10 minutos
- Reflexión estratégica
