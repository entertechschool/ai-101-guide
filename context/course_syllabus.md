# AI Tools (No-Devs)

## Objetivos

1. **Desarrollar visión estratégica de IA aplicada a productos digitales**
   - Comprender el ecosistema de IA y sus capacidades reales vs. hype en 2025
   - Identificar oportunidades de innovación con IA en diferentes industrias
   - Distinguir entre productos IA-first vs. features de IA
   - Reconocer patrones de productos IA exitosos y causas de fracasos comunes

2. **Dominar metodologías de Product Management centradas en IA**
   - Aplicar Design Thinking y Jobs-to-be-Done para descubrir problemas reales
   - Validar demanda utilizando técnicas Lean sin escribir código
   - Definir MVPs funcionales con scope realista y funcionalidades priorizadas
   - Gestionar roadmaps de producto desde MVP hasta escalamiento

3. **Construir productos IA funcionales con herramientas no-code**
   - Crear prototipos interactivos utilizando stack no-code (Claude, v0.dev, Make, Airtable)
   - Integrar APIs de IA en flujos de trabajo automatizados
   - Diseñar interfaces de usuario efectivas para productos IA
   - Implementar testing de UX y validación con usuarios reales

4. **Implementar estrategias de lanzamiento y escalamiento responsable**
   - Definir KPIs y dashboards para medir éxito de productos IA
   - Identificar y mitigar riesgos éticos y sesgos en IA
   - Evaluar viabilidad técnica y planificar evolución del producto

## Módulos y Clases

### Módulo 1: Fundamentos + Herramientas
**Semanas 1-2**

**1. Fundamentos de IA + Identificar Tu Oportunidad** (2.5h)
- IA, ML, LLMs: diferencias clave sin tecnicismos
- Capacidades reales vs. limitaciones de IA en 2025
- Patrones de productos IA exitosos (análisis de 4 casos)
- Framework "AI Opportunity Canvas" 
- Setup de Claude y Perplexity como research tools
- **Taller:** Identificar oportunidad en tu industria (40 min)
- **Entregable:** AI Opportunity Canvas completado + research documentado
- **Homework (2h):** Refinar canvas, identificar 5 usuarios potenciales, explorar productos similares

**2. Validación de Problemas + Research con IA** (2.5h)
- Jobs-to-be-Done framework aplicado a IA
- Técnicas de entrevistas: "The Mom Test"
- Diseñar preguntas de validación efectivas
- Usar Claude/Perplexity para análisis de entrevistas
- **Taller:** Crear Interview Script + role-play de entrevistas (65 min)
- **Entregable:** Interview Script validado + Problem Definition Canvas v0.5
- **Homework (2h):** Realizar 3-5 entrevistas reales + análisis con Claude

**3. Validación Lean + Landing Page con v0.dev** (2.5h)
- Lean Startup: build-measure-learn aplicado a productos IA
- Copywriting basado en insights de usuarios
- Introducción completa a v0.dev
- **Taller:** Crear landing page funcional en 60 min
- Métricas de validación y plan de distribución
- **Entregable:** Landing page publicada con URL pública
- **Homework (2h):** Conseguir 20-30 visitas + analizar métricas + refinar copy

**4. Stack No-Code Completo + PRD del MVP** (2.5h)
- Arquitectura de stack no-code (frontend + automation + data + IA)
- Setup de Make: flujos automatizados y webhooks
- Setup de Airtable: estructura de datos relacional
- Integración de Claude API en workflows
- **Taller:** Crear flujo end-to-end funcional (80 min)
- Definición de alcance del MVP con PRD simplificado
- **Entregable:** Stack funcional + PRD v1.0 + user flow visual
- **Homework (2h):** Completar PRD, refinar flujo, preparar user flow

#### Salida del Módulo 1:
✅ Problema validado con 3-5 entrevistas + 20-30 visitas en landing  
✅ Landing page funcional publicada  
✅ Stack no-code configurado: Claude + v0.dev + Make + Airtable  
✅ PRD v1.0 con alcance de MVP definido  
✅ Flujo automatizado funcional (webhook → Airtable → Claude → email)

### Módulo 2: Descubrimiento + Prototipado
**Semanas 3-4**

**5. Análisis Competitivo para Copiar Features Validadas** (2.5h)
- Feature comparison matrix simplificada (5-7 competidores)
- Uso de IA para research de mercado acelerado (Perplexity + Claude)
- Identificar features validadas para adaptar (no para diferenciarse)
- **Taller:** Competitive analysis express con Claude (55 min)
- **Entregable:** Feature matrix + 3-5 features a copiar justificados
- **Homework (2h):** Research profundo de 2 competidores + validar features con usuarios

**6. Definición de MVP: Funcionalidades Críticas** (2.5h)
- Qué es un MVP en contexto de productos IA
- Must-have vs. Nice-to-have (framework simple de priorización)
- User Stories para no-developers con criterios de aceptación técnicos
- **Taller:** PRD v2.0 con 3-5 must-haves únicamente (50 min)
- **Entregable:** PRD v2.0 completo con criterios técnicos viables
- **Homework (2h):** Validar PRD con 2-3 usuarios + confirmar viabilidad técnica + crear user flows

**7. Prototipado Rápido con v0.dev** (2.5h)
- Principios de diseño de productos IA (transparencia, feedback, control, loading states)
- Wireframing de flujos de usuario para interfaces IA
- Prototipado iterativo con v0.dev (prompts avanzados)
- **Taller:** Prototipo clickeable de 2-3 flujos clave (60 min)
- **Entregable:** Prototipo interactivo funcional (6-9 pantallas)
- **Homework (2h):** Refinar prototipo + testing con 3 usuarios + preparar assets para integración

**8. Construcción del MVP: Integración Completa** (2.5h)
- Arquitectura de integración: frontend + IA + backend no-code
- Conexión frontend (v0.dev) → Make → Airtable → Claude API
- Debugging y troubleshooting de integraciones
- **Taller:** Integrar todos los componentes del MVP (70 min)
- **Entregable:** MVP funcional al 70-80% (frontend + backend integrados)
- **Homework (2h):** Completar MVP al 80% + documentar limitaciones técnicas + reclutar usuarios beta

#### Salida del Módulo 2:
✅ Feature matrix de competencia (insights accionables)  
✅ PRD v2.0 con user stories y criterios técnicos  
✅ Prototipo funcional testeado con usuarios  
✅ MVP al 80% funcional con integraciones reales  
✅ Documentación de limitaciones técnicas conocidas

### Módulo 3: Validación + Mejora Iterativa
**Semanas 5-6**

**9. Testing y Validación de MVP en Usuarios Reales** (2.5h)
- Diseño de pruebas de usabilidad para productos IA
- Reclutamiento de 5-7 usuarios beta (moderated testing + think-aloud)
- Recolección y análisis de feedback cualitativo
- Identificación de friction points críticos
- **Taller:** Sesión de testing en vivo + análisis con Claude (60 min)
- **Entregable:** Testing report con 10+ insights documentados
- **Homework (2h):** Testing con 5-7 usuarios reales + análisis consolidado

**10. Métricas, KPIs y Dashboards para Productos IA** (2.5h)
- Definir 3-5 métricas core (vanity vs. accionables)
- KPIs específicos para productos IA (trust score, accuracy percibida, engagement)
- Framework: Input-Output-Outcome
- **Taller:** Dashboard funcional en Google Sheets (50 min)
- **Entregable:** Dashboard con tracking + datos de baseline
- **Homework (2h):** Configurar tracking automático + recolectar datos + analizar trends

**11. Iteración y Mejora del MVP** (2.5h)
- Priorización de mejoras (Impact vs. Effort matrix)
- Framework de iteración rápida (build-measure-learn acelerado)
- **Taller:** Implementar 2-3 quick wins en vivo (75 min)
- Validar cambios con métricas (antes vs. después)
- **Entregable:** MVP v1.1 mejorado + changelog + roadmap v1.2
- **Homework (2h):** Implementar mejoras adicionales + validar con usuarios + preparar materials

**12. Preparación de Portfolio y Presentación** (2.5h)
- Estructura de case study profesional (6 secciones)
- Crear demo video efectivo con Loom (3-5 min)
- Diseñar presentación técnica de 10 min (NO pitch de ventas)
- **Taller:** Case study + demo video (80 min)
- **Entregable:** Portfolio case study + demo profesional + presentación
- **Homework (2h):** Refinar case study + preparar para presentación final Clase 16

#### Salida del Módulo 3:
✅ Testing report con insights de 5-7 usuarios  
✅ Dashboard de KPIs funcional con datos reales  
✅ MVP v1.1 con mejoras validadas por métricas  
✅ Roadmap de iteración (v1.1 → v1.2)  
✅ Case study completo + demo video profesional

### Módulo 4: Escalabilidad + Cierre
**Semanas 7-8**

**13. Escalado: De MVP a Producto Maduro** (2.5h)
- Señales de product-market fit en productos IA
- Roadmap de evolución: v1.0 → v1.1 → v2.0 (3 meses)
- Cuándo y cómo involucrar developers (transición a código)
- Limitaciones del stack no-code y cuándo migrar
- **Taller:** Product roadmap de 3 meses con milestones (60 min)
- **Entregable:** Roadmap 3 meses + plan de transición técnica
- **Homework (2h):** Validar roadmap con stakeholders/usuarios + ajustar prioridades

**14. Ética, Sesgo y Responsabilidad en Productos IA** (2.5h)
- Principios de IA responsable (fairness, transparency, accountability)
- Identificación de sesgos en modelos y datos
- Checklist práctico de evaluación ética
- Casos reales de productos con issues éticos
- **Taller:** Matriz de riesgos éticos + plan de mitigación (65 min)
- **Entregable:** Ethics assessment completo + mitigaciones
- **Homework (2h):** Evaluar producto con checklist + implementar mejoras éticas

**15. Viabilidad Técnica y Próximos Pasos** (2.5h)
- Evaluar viabilidad técnica del MVP actual
- Identificar limitaciones del stack no-code
- Cuándo escalar vs. cuándo pivotar
- Roadmap personal: próximos skills a desarrollar
- Overview de pricing básico (15 min): modelos, unit economics
- **Taller:** Technical viability report + learning roadmap (70 min)
- **Entregable:** Viability report + learning roadmap personal (6 meses)
- **Homework (2h):** Plan próximos 3-6 meses (producto + personal) + refinar presentación

**16. Presentación Final de Proyecto + Reflexión Estratégica** (2.5h)
- Presentaciones de proyectos finales (10 min c/u)
- Evaluación de pares con rúbrica estructurada
- Feedback del facilitador
- Reflexión: lecciones aprendidas y próximos pasos
- Gallery walk de portfolios
- **Entregable:** Presentación final + reflexión estratégica escrita
- **Homework:** Publicar case study en LinkedIn/portfolio

#### Salida del Módulo 4:
✅ Roadmap de 3 meses con milestones claros  
✅ Ethics assessment + mitigaciones implementadas  
✅ Technical viability report  
✅ Learning roadmap personal (próximos 6 meses)  
✅ Presentación final + portfolio case study publicado

## Proyecto Final del Curso

### **MVP Funcional de Producto IA + Portfolio Profesional**
Proyecto integrador construido clase a clase durante las 8 semanas.

**Componentes del proyecto:**
- **Problem Definition Canvas**: Problema validado con usuarios reales
- **MVP Funcional**: Producto no-code desplegado y accesible vía URL
- **Testing Report**: Insights de 5-7 usuarios beta con mejoras implementadas
- **Dashboard de KPIs**: Métricas en tiempo real con datos reales
- **Roadmap de Producto**: Evolución planificada para 3 meses
- **Ethics Assessment**: Matriz de riesgos y mitigaciones
- **Portfolio Case Study**: Documentación completa del proceso

**Entregables finales:**
- MVP funcional desplegado (link público)
- Demo video profesional (3-5 min)
- Portfolio case study completo
- Presentación final de 10 minutos
- Reflexión estratégica: aprendizajes y próximos pasos

## Duración Total del Curso

**Tiempo sincrónico:** 16 clases × 2.5h = 40 horas  
**Tiempo asincrónico:** 16 tareas × 2h = 32 horas  
**Total:** 72 horas en 8 semanas (~9h/semana)

**Formato:**
- 8 semanas | 2 clases/semana (martes y jueves)
- Online en vivo (cohort-based)
- Sin grabaciones como principal (solo referencia)
