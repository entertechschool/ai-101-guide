Diseña la fuente de datos de tu sistema con 3 pestañas

Arquitectura de 3 pestañas

Cada pestaña tiene un propósito claro y frecuencia de cambio distinta.

VentasSemanaActual  →  Operación (1 fila por transacción)
Config              →  Parámetros del negocio (cambios raros)
Historico           →  Memoria semanal (1 fila por período)

Operativa vs Configuración

La diferencia que hace sostenible la automatización.

AspectoOperativaConfig
CambioVarias veces/día1 vez/mes
OrigenCorreos, formsDecisión gerencial
EjemploVenta registradaMeta semanal
Filas típicas50-5004-20

Rangos nombrados

Apodos para rangos que sobreviven a cambios de layout.

Antes: Make → A1:G50     (se rompe si agregás columna)
Despues: Make → RangoVentas (sigue funcionando siempre)

Definir en:  Datos → Rangos con nombre
RangoVentas    = VentasSemanaActual!A:G
RangoConfig    = Config!A:C
RangoHistorico = Historico!A:E

La columna Descripción

El campo clave que Gemini usará para generar insights en la Clase 5.

Monto: S/ 2,800
Descripción: "Renovación grande, cliente retenido
              después de 2 meses de negociación"

  y explica el POR QUÉ del dato, no solo el QUÉ.
