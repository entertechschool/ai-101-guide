Prompt JSON estructurado

Pedir SOLO JSON evita 90% de errores de Parse JSON.

Eres analista. Responde SOLO JSON válido, sin markdown
ni texto adicional. Si un campo no está en los datos, usa null.

Campos requeridos:
{ "resumen": "...",
  "hallazgo_1": "...",
  "hallazgo_2": "...",
  "riesgo_1": "...",
  "accion_1": "..." }

DATOS:
[datos del Sheet aquí]

REGLAS:
- Español latinoamericano
- Máximo 25 palabras por campo
- Compara contra meta cuando aplique
