Sesión 05 · Plantillas con placeholders

Plantillas con placeholders

Genera documentos con formato profesional automáticamente

¿Qué es una plantilla?

Esqueleto reutilizable: el formato es fijo, los datos cambian.

┌──────────────────────────────┐
│  REPORTE MENSUAL DE FACTURAS │
│  {{mes}} {{anio}}            │
│  Total:    {{total}}         │
│  Top prov: {{top_proveedor}} │
└──────────────────────────────┘
Make reemplaza cada {{...}} con un dato real

Placeholders {{variable}}

Los huecos que Make rellena. El nombre debe coincidir exacto.

✅  {{total}}          ·  mapeo "total"        → reemplaza
❌  {{Total}}          ·  mapeo "total"        → no (mayúscula)
❌  {{ total }}        ·  mapeo "total"        → no (espacios)

Tipos: texto · número · fecha · link de imagen

Formato de datos

Vestir el dato antes de inyectarlo al placeholder.

1500        → S/ 1,500.00     formatNumber(monto; 2)
2026-06-01  → 1 de junio 2026 formatDate(fecha; "...")
0.12        → 12%

Make tiene funciones built-in para todas.
