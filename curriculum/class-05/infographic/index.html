Tu primer agente: recibe, piensa y clasifica sin que hagas nada

Automatización vs Agente IA

La diferencia fundamental: reglas fijas vs decisión inteligente.

Automatización Agente IA
Lógica IF/THEN fijo La IA DECIDE el THEN
Ejemplo "Presione 1 para soporte" Lee el mensaje y decide a quién
Adaptable No — cambiar reglas Sí — mejorar el prompt

Arquitectura: Form → Webhook → IA

3 componentes que convierten un formulario en un agente que piensa.

┌──────────────────┐     ┌──────────┐     ┌──────────────┐
│ FORMULARIO + DBG │ ──→ │ WEBHOOK  │ ──→ │  IA DECIDE   │
│ (v0 + Vercel)    │     │ (Make)   │     │ (OpenRouter)  │
└──────────────────┘     └──────────┘     └──────────────┘

Formulario  → ¿De dónde vienen los datos?
Webhook     → ¿Qué activa el flujo?
IA Decide   → ¿Qué criterio usa? (SystemPrompt)

SystemPrompt vs UserPrompt

El SystemPrompt es el "manual del empleado". El UserPrompt es cada tarea que recibe.

SystemPrompt (permanente):
  "Eres un agente de triage. Clasifica mensajes
   en: URGENTE, CONSULTA, VENTA. Regla: deadline
   < 48h → siempre URGENTE."

UserPrompt (cambia por mensaje):
  "Nombre: María | Email: m@empresa.com
   Mensaje: Mi pedido no llegó y es para mañana"

→ Resultado: URGENTE (deadline implícito)

La fórmula: supervisión no es opcional

Un agente amplifica tu criterio — no lo reemplaza.

Agente útil =
  Buen SystemPrompt
  + Buena supervisión
  + Mejora continua

⚠️ Basura entra → basura sale (a escala)
⚠️ La IA no tiene sentido común
⚠️ Automatizar un mal proceso = errores más rápidos
