Agente Inteligente — Branching, acción y registro

El agente decide, actúa diferente según la decisión y registra todo

Flujo lineal vs Branching

De "todos reciben lo mismo" a "cada categoría tiene su propia acción".

LINEAL (C05):
  Webhook → OpenRouter → Gmail
  (todos los mensajes → mismo email)

BRANCHING (C06):
  Webhook → OpenRouter → Router
    ├─ 🔴 URGENTE  → Gmail rojo
    ├─ 🔵 CONSULTA → Gmail normal
    └─ 🟢 VENTA    → Gmail verde + Sheets

Router y Filters: el agente que decide rutas

El Router divide el flujo. Cada Filter es una condición que activa una ruta.

Router = divide el flujo en rutas
Filter = condición de cada ruta

Ejemplo de Filter en Make:
  Ruta 1: output contains "URGENTE"  → 🔴
  Ruta 2: output contains "CONSULTA" → 🔵
  Ruta 3: output contains "VENTA"    → 🟢

⚠️ "contains" es case-sensitive
   "URGENTE" ≠ "Urgente" ≠ "urgente"

Google Sheets: la memoria del agente

Sin registro, no puedes auditar ni mejorar. El logging convierte un agente en algo profesional.

Sin logging:
  "Mi agente clasifica bien" → ¿Cómo lo sabes?
  "Se equivocó" → ¿Cuántas veces? ¿En qué?

Con logging (Google Sheets):
  Timestamp | Nombre | Email | Mensaje | Categoría | Acción
  ─────────────────────────────────────────────────────────
  Cada decisión queda registrada
  → Auditar, filtrar, analizar tendencias
  → Base para mejorar el SystemPrompt con datos

Mismo modelo, mismos mensajes, resultados diferentes

La diferencia nunca es la herramienta — siempre es el SystemPrompt.

Battle: 5 mensajes idénticos → todos los agentes

Agente A: 3/5 correctos  (SystemPrompt genérico)
Agente B: 5/5 correctos  (SystemPrompt con reglas)

Mismo Grok. Mismos mensajes.
La diferencia: las REGLAS en el SystemPrompt.

Fórmula del agente inteligente:
  Buen SystemPrompt + Filters exactos + Supervisión
Router Módulo de Make que divide el flujo en múltiples rutas condicionales
Filter Condición que activa una ruta del Router (ej: "contains URGENTE")
Logging Registrar cada decisión del agente en Google Sheets para auditoría
Branching Flujo que se divide en caminos según condiciones — no todos van al mismo destino
