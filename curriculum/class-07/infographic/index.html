De clasificar a generar

En C05-C06 la IA ponía etiquetas. En C07 la IA crea contenido profesional.

C05-C06: CLASIFICAR              C07: GENERAR
─────────────────────            ─────────────────────
Input                            Input
→ IA clasifica                   → IA #1 ANALIZA
→ Router decide                  → IA #2 GENERA
→ Email etiqueta                 → Email creado

Output: etiqueta (URGENTE)       Output: contenido (email completo)
1 IA, 1 decisión                 2 IAs encadenadas, 2 trabajos

Arquitectura: 5 módulos, 2 cerebros

Cada IA se especializa en 1 tarea = mejor calidad en ambas.

Realidad: los primeros outputs serán mediocres

La habilidad no es que funcione perfecto al primer intento — es saber diagnosticar y mejorar.

Problemas esperados:

⚠️ OR#1 devuelve texto en vez de JSON
   → Agregar: "Responde SOLO con JSON, sin markdown"

⚠️ OR#2 genera email genérico
   → Más instrucciones de formato, tono, secciones

⚠️ Gmail muestra HTML como texto plano
   → Marcar opción "HTML" en el módulo Gmail

⚠️ Los SystemPrompts necesitan 2-3 iteraciones
   → Iterar es el proceso, no el fallo
Encadenamiento Usar el output de una IA como input de otra en un pipeline
OR#1 (Analizar) Primera IA: lee input crudo y extrae estructura en JSON
OR#2 (Generar) Segunda IA: toma el JSON y genera contenido profesional
Deploy Publicar tu proyecto en internet con URL pública (Vercel)
