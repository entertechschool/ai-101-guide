## FUNDAMENTO 1 · ESTRUCTURA DEL PROYECTO

*Problema → solución → arquitectura*

- **PROBLEMA** — qué se resuelve
- **SOLUCIÓN** — cómo se aborda
- **ARQUITECTURA** — qué módulos usar

> Antes de tocar Make, ten claras las 3.

---

## FUNDAMENTO 2 · DIAGRAMAR ANTES DE CONSTRUIR

*Una hoja con cajas y flechas ahorra horas*

- ¿Cuál es el trigger? (evento o programado)
- ¿Qué módulos intermedios necesito?
- ¿Qué hace la IA en cada paso?
- ¿Cuál es el output final y a quién va?

---

## FUNDAMENTO 3 · ITERACIÓN

*Construir, probar, refinar*

- **CONSTRUIR** — una v1 mínima
- **PROBAR** — con datos reales
- **REFINAR** — ajustar y repetir

> El primer intento nunca es el último — y está bien.

## MINI-PROYECTO · TU PROYECTO

*Caso propio + flujo funcionando*

**Individual · acompañamiento 1 a 1**

### QUÉ HACER

1. Elegir el caso real (algo que haces seguido y te quita tiempo)
2. Diagramar el flujo en una hoja (trigger, módulos, output)
3. Construir la versión **v1 mínima** (que funcione punta a punta)
4. Probar con **tus datos reales** (no de juguete)
5. Refinar e iterar (prompts, filtros, mapeos)

✓ **Verificación:** Tu primer flujo propio corriendo con datos reales
