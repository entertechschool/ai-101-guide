# Lab 08: Demo Day

## 🎯 Objetivo

**Sustentar tu proyecto integrador** ante el grupo en 5 minutos, con demo en vivo, y salir con un **roadmap personal** de tus próximas automatizaciones.

---

## 🔑 Conceptos Clave

- **Estructura de expo** — caso → demo → resultados → aprendizajes.
- **Demo en vivo** — mostrar el sistema funcionando con datos reales.
- **Resultados cuanti + cuali** — tiempo/costo + qué aprendiste.

## Mini-proyecto: tu Demo Day

> Cada estudiante presenta en 5 minutos y recibe feedback del grupo.

### Paso 1: Presenta en 5 minutos (caso → demo → resultados → aprendizajes)

```
CASO (1 min):        "Antes, [tarea] me tomaba [X tiempo] porque [causa]."
DEMO (2 min):        el sistema funcionando en vivo (ver Paso 2)
RESULTADOS (1 min):  tiempo ahorrado, costo, items procesados
APRENDIZAJES (1 min): qué problema tuviste y cómo lo resolviste
```

### Paso 2: Demo en vivo del flujo

El corazón de la presentación. No slides — el sistema funcionando:

1. Dispara tu flujo con datos reales (sube un archivo / envía un correo).
2. Muestra cómo se procesa y aparece el resultado.
3. Si algo falla: explica qué iba a pasar y muestra el video de respaldo.

✓ **Verificación:** El grupo vio tu sistema funcionar (o entendió qué hace).

### Paso 3: Q&A del grupo

1 minuto de preguntas técnicas y de aplicación entre presentaciones.

### Paso 4: Feedback estructurado

El grupo comparte, por cada demo: **qué funciona bien** + **qué mejorarías**. Constructivo, breve.

### Paso 5: Roadmap personal

Antes de cerrar, escribe en 3-4 líneas:

```
Mi próxima automatización será [proceso].
Los datos salen de [origen] y van a [destino].
La construiré en las próximas [semanas].
```

✓ **Verificación:** Presentaste, recibiste feedback y tienes tu roadmap escrito.
