# AI-101: Fundamentos y Herramientas de IA para Profesionales

## Objetivos

1. **Visión práctica de IA aplicada a workflows y productos**
   - Capacidades reales vs. hype en 2025
   - Identificar oportunidades de automatización e innovación
   - Patrones de éxito en implementaciones IA

2. **Metodologías de validación y construcción**
   - Jobs-to-be-Done para problemas reales
   - Validación Lean sin código
   - Scope realista y soluciones funcionales

3. **Construcción con herramientas no-code**
   - Stack completo: Claude + v0.dev + Make + Airtable
   - Integración de APIs en flujos automatizados
   - Diseño de interfaces efectivas

4. **Lanzamiento e iteración**
   - Testing con usuarios reales
   - Métricas básicas de impacto
   - Portfolio profesional y presentación

---

## Módulos y Clases

### Módulo 1: Descubrimiento + Validación
**4 clases × [2.5h vivo + 2h async] = 18 horas**

**1. IA Hoy + Tu Oportunidad**
- IA, ML, LLMs sin tecnicismos
- **Patrones duales:** 4 productos exitosos + 3 automatizaciones (Marketing, Ops, CS)
- AI Opportunity Canvas (producto O workflow)
- Lab: Identificar oportunidad Track A (producto) o Track B (workflow)

**2. Validación de Problemas + Research con IA**
- Jobs-to-be-Done + "The Mom Test"
- **Adaptación dual:** Validación externa vs. pain points internos
- Lab: Interview Script + role-play

**3. Validación Lean + Landing Page con v0.dev**
- Build-measure-learn aplicado a productos Y workflows
- Copywriting desde insights
- Lab: Landing (producto para mercado O demo interna)

**4. Stack No-Code + Arquitectura**
- Arquitectura: frontend + automation + data + IA
- Setup: Make, Airtable, Claude API
- **Demo dual:** SaaS vs. automatización de reportes
- Lab: Flujo end-to-end + Implementation Brief v1.0

**Herramientas:** Claude, Perplexity, v0.dev, Make, Airtable

**Salida del Módulo:**
✅ Problema/oportunidad validado (3-5 entrevistas)
✅ Landing page o demo interno desplegado
✅ Stack no-code configurado y funcional
✅ Implementation Brief v1.0 con scope definido

---

### Módulo 2: Construcción
**4 clases × [2.5h vivo + 2h async] = 18 horas**

**5. Benchmark + Definición de MVP**
- Feature matrix rápida (3 competidores clave)
- MVP/MWP: Must-have vs. Nice-to-have
- **Dual:** Features validadas (productos) o mejores prácticas (workflows)
- Lab: Analysis con Claude + Brief v2.0 (3 must-haves)

**6. Prototipado Rápido con v0.dev**
- Principios de diseño IA: transparencia, feedback, control
- Wireframing de flujos
- Lab: Prototipo de 2-3 flujos (6-9 pantallas)

**7. Integración Completa**
- Conexión v0.dev → Make → Airtable → Claude API
- Debugging y troubleshooting
- Lab: Integrar MVP/MWP end-to-end

**8. Testing + Métricas Básicas**
- Testing con 3-5 usuarios beta
- 3 métricas core (vanity vs. accionables)
- Lab: Sesiones de testing + Dashboard básico en Sheets

**Herramientas:** v0.dev avanzado, Make, APIs/webhooks, Google Sheets

**Salida del Módulo:**
✅ Benchmark completado + Brief v2.0 con funcionalidades priorizadas
✅ Prototipo funcional testeado (6-9 pantallas)
✅ MVP/MWP al 80% con integraciones reales
✅ Testing report + Dashboard de KPIs básico

---

### Módulo 3: Lanzamiento
**4 clases × [2.5h vivo + 2h async] = 18 horas**

**9. Iteración Rápida**
- Impact vs. Effort matrix
- Build-measure-learn acelerado
- Lab: Implementar 2-3 quick wins + medir impacto

**10. Portfolio + Demo Video**
- Case study profesional (6 secciones)
- Demo video con Loom (3-5 min)
- Lab: Case study + demo video

**11. Roadmap + Ética Práctica**
- Roadmap 3 meses (v1.0 → v1.1 → v2.0)
- Checklist ético práctico (10 items)
- Señales de cuándo escalar o migrar a código
- Lab: Roadmap con milestones + Ethics quickscan

**12. Presentación Final**
- Presentaciones (10 min c/u) - productos y workflows
- Feedback de pares y facilitador
- Gallery walk + reflexión estratégica

**Herramientas:** Loom, Google Sheets, Notion

**Salida del Módulo:**
✅ MVP/MWP v1.1 con mejoras validadas
✅ Case study completo + demo video profesional
✅ Roadmap 3 meses + ethics quickscan
✅ Presentación final + portfolio publicado

## Proyecto Final

### **Implementación IA Funcional + Portfolio Profesional**
Proyecto iterativo construido clase a clase durante 6 semanas.

**Dos tracks:**
- **Track A:** Producto IA para mercado externo
- **Track B:** Herramienta/automatización IA para tu rol

**Componentes:**
- Problem Definition Canvas validado (3-5 entrevistas)
- Implementación desplegada (URL pública)
- Testing Report (3-5 usuarios beta)
- Dashboard KPIs básico
- Roadmap 3 meses
- Ethics Quickscan
- Portfolio Case Study

**Entregables:**
- Implementación funcional (link público)
- Demo video (3-5 min)
- Case study completo
- Presentación técnica (10 min)
